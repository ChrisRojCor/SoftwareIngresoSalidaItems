# TSM - Technical Service Manager

## 🚀 Overview
TSM is a professional Technical Service Manager. This project demonstrates a technical migration from a **Legacy JSP Monolith** to a modern **Decoupled Architecture**.

## 🛠️ Tech Stack
- **Backend:** Java 21, Spring Boot 3, MySQL.
- **Frontend:** React (Vite), Tailwind CSS.
- **Tools:** Git, Maven, Node.js.

## 📈 Project Evolution
1.  **Legacy Branch:** Original version using JSP and server-side rendering.
2.  **Develop Branch:** Current active migration to a REST API + React frontend.
